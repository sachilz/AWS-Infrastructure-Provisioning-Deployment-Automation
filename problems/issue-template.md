# Issue Log Template

Copy and paste this template into [`resolved-issues.md`](resolved-issues.md) whenever you encounter and resolve a new problem.

---

### [ISSUE-00X] Short Descriptive Title of the Error

- **Date**: YYYY-MM-DD
- **Component**: AWS | Terraform | Ansible | Linux / Nginx | Git
- **Severity**: Low | Medium | High (Blocker)

#### 1. What Happened (Symptoms)
Explain what you were attempting to do and what failed.

```bash
# The exact command executed
$ example-command --flag
```

#### 2. Exact Error Output
Paste the terminal or log error message here:
```text
Error: [paste error message here]
```

#### 3. Root Cause Analysis
Explain *why* the error occurred. What was missing, misconfigured, or misunderstood?

#### 4. Solution / Fix
Explain the exact steps or code changes applied to fix the issue:
```bash
# Commands run or code edits made
```

#### 5. Prevention / Takeaway
What rule or practice will prevent this error in future deployments?
