## 💡 How to Use This Folder

1. **Write As You Build**: Whenever you learn a new concept (e.g., what a CIDR block is, why Terraform uses a lock file, why Ansible is idempotent), add a brief note.
2. **Focus On The "Why"**: Don't just paste code snippets—explain *why* a particular approach was chosen over another.
3. **Use Simple Language**: Explain concepts simply in your own words (Feynman Technique). If you can explain it simply here, you can explain it clearly in an interview!
